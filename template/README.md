# Artwork Template

Starter structure for a new io-archive artwork.

## Use

1. Copy this folder and rename it for the artwork slug.
2. Update the page title, panel title, and panel description in `index.html`.
3. Replace the placeholder drawing in `main.js` with the artwork.
4. Adjust colors in `styles.css`.
5. Add the finished artwork to the `artworks` array in the root `app.js`.

The bottom-left description panel matches the layout used by `night-survey`.
