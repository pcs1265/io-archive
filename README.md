# IO-Archive

IO-Archive is a collection of interactive web artworks.

The name means Input Output Archive, The base of interaction: Input and Output

The root page presents the available pieces of artwork as an archive.

Live site: https://pcs1265.github.io/io-archive/

## Artworks

- [Letterain](letterain/) - Falling letters fracture into R, A, I, and N when they strike the ground.
- [Auroral Vines](auroral-vines/) - Bioluminescent hanging vines glow and swing under touch.
- [Night Survey](night-survey/) - An interactive sketch that grows constellation graphs from click or touch input.
